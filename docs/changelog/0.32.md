# Detailed notes for 0.32

## [0.32.0] - 2026-10-09

### Breaking

- Adopt the 88-file Shared Tooling 0.2.1 snapshot at
  `06b2e22f6bd213f1a590eb2a8797aee34c42dd69`, with accurate committed provenance.
  The IC bundle supplies Quill, ICP CLI, didc, ic-wasm and wasm-opt. PocketIC
  catalog rows and installer/version/archive branches are removed. Run explicit
  `make install-ic-tools` to activate the new bundle; an old six-tool bundle fails
  its offline check. Old bundles, receipts and failed candidates stay retained.
  [#38](https://github.com/dragginzgame/ic-memory/issues/38),
  [Shared #76](https://github.com/dragginzgame/shared-tooling/issues/76).
- Use Testkit's published 0.25.4 CLI for PocketIC selection, authenticated setup,
  offline checks and managed launch. `make install-runtime-server` explicitly
  prepares the exact registry CLI and server; `make runtime-server-check` prints
  its admitted server path without downloads. `make test-runtime` builds the
  supplied current Wasm and independent runner before managed launch. The runner
  now requires `IC_TESTKIT_POCKET_IC_URL`; the former URL variable is removed.
  Library/release gates do not install or require a runtime server. Separate CI
  jobs qualify setup and installed invalid-IO/upgrade rollback on all three native
  hosts. The locked PocketIC 16.0.0 client is unchanged; server selection belongs
  to Testkit and old 16.0.0 server evidence does not qualify its new 16.1.0 pairing.
  [#38](https://github.com/dragginzgame/ic-memory/issues/38).

### Fixed

- Require a single JSON exception catalog before dependency finding suppression,
  closing the malformed-first-document bypass. Isolated formatting hooks find
  prepared tools in the original checkout without relying on an interactive PATH
  export. Preserve selected-index isolation, exact versions and unrelated edits.
  [#38](https://github.com/dragginzgame/ic-memory/issues/38),
  [Shared #86](https://github.com/dragginzgame/shared-tooling/issues/86),
  [Shared #85](https://github.com/dragginzgame/shared-tooling/issues/85).
- Consume the final validated IC pin row even without a trailing newline during
  both installation and offline version admission; selected pin bytes remain
  intact. [Shared #87](https://github.com/dragginzgame/shared-tooling/issues/87).
- Claim release-fixture directories through exclusive filesystem creation and
  skip occupied names. Retained failures no longer block later test runs after
  process ID reuse; unrelated files are preserved. Other filesystem errors still
  stop construction, and successful fixtures clean only their own directory.
  Remove the redundant process-local atomic counter.
  [#37](https://github.com/dragginzgame/ic-memory/issues/37).
- Cover occupied directories and files through fixture construction and cleanup.
  This correction preserves production APIs, durable formats and release behavior.

### Changed

- Qualify the maintainer-selected Host filesystem/artifact 0.9.0 manifest/lock
  update, preserving disabled default features. The published library Rust
  sources are unchanged from 0.8.10. Keep this dependency evidence
  distinct from Memory's Shared snapshot and Testkit adoption.
- Retain CLI install attempts, provisioned server bundles and runtime diagnostics
  in failure archives without applying host/IC compact retention to those new
  evidence owners.
