# 0.35 release notes

## [0.35.1]

### Setup prerequisite checks and diagnostics

Refresh the same 90-file selection from committed Shared Tooling **0.3.1**,
`fa452afaa5012866eb1c20820dfa8038c106e7ec`. Common `install-tools` checks
platform/catalog and checkout-selected Rust/Cargo before host, IC, Cargo or
product installation. These silent read-only preflight calls do not install
toolchains, download tools or replace retained receipts. Narrow setup commands
and ordinary offline `tools-check` retain their existing roles.

Host-tool checks report the failing executable, expected version, selected path,
reason, available probe output and repair command. Byte authentication still
precedes executable probes, and earlier bundles and failure evidence remain.
The upstream fixtures qualify prerequisite refusal and aggregate ordering,
including parallel Make and product extensions. No new consumer gate or tool
selection is introduced. [#51](https://github.com/dragginzgame/ic-memory/issues/51),
[Shared #101](https://github.com/dragginzgame/shared-tooling/issues/101).

This is a compatible tooling patch; the canister API, durable format and both
dependency graphs are unchanged.

See [qualification](../release-workflow-qualification.md#0351-shared-031-setup-preflight).

## [0.35.0] - 2026-10-10

### Breaking tooling setup: complete common tools

Adopt committed Shared Tooling **0.3.0** at
`88a73139a0f083344c41a6f6f4b5c3a8aca7dc1d` through the canonical exporter.
The common aggregate always installs/checks jq, yq, ripgrep with PCRE2, cloc,
five IC tools, cargo-sort, cargo-sort-derives and candid-extractor in that order.
Direct host-installer `--with-ripgrep` and `--with-cloc` options are removed;
call the existing common targets instead. Prepare the declared Rust toolchain
first, run `make install-tools`, then run offline `make tools-check`.
[#50](https://github.com/dragginzgame/ic-memory/issues/50),
[Shared #98](https://github.com/dragginzgame/shared-tooling/issues/98).

Memory uses the same canonical aggregate in CI and coherent release preflight.
Standalone validation checks complete common admission before dependent builds,
including under parallel Make. Interrupted metadata recovery checks the retained
selection without replaying setup. CI selects local Cargo tools, removing its
duplicate global formatter installation; exact two-workspace formatting remains.
PocketIC/Testkit preparation stays a separate explicit command and is not added
to library gates. The canister API, durable format, compiler and dependency
selections are unchanged. This setup/installer contract cut requires a minor
release and supersedes the unreleased compatible 0.34.2 candidate.

### CI inspection

The preceding 0.2.14 CI-helper repair is carried forward. Failed, unfinished or
unknown runs with missing failed-step logs report unavailable evidence;
completed successful, neutral or skipped runs may legitimately have none.
Retrieval failures preserve status and retain partial observations.
[Shared #97](https://github.com/dragginzgame/shared-tooling/issues/97).
The upstream fixture remains part of Memory's tooling gate. Earlier focused
[evidence](../release-workflow-qualification.md#0342-shared-0214-ci-log-evidence)
retains its original inputs; full adoption evidence belongs to the current batch.

See [qualification](../release-workflow-qualification.md#0350-shared-030-complete-common-tools).
