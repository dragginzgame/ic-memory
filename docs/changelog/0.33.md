## [0.33.2]

`04e07b4bf54e7aeb03eb7804a845cee27b7305df`. Eight selected test fixtures now
declare their required helpers, all already present in Memory's selection.
The canonical exporter refuses incomplete selections before changing consumer
files. The upstream distribution integration suite remains owned by Shared
Tooling; Memory retains its actual snapshot and local checks.
[Shared #73](https://github.com/dragginzgame/shared-tooling/issues/73).

and refuses conflicting selections without changing configuration. Hook setup and
execution preserve newline-ending checkout paths. Memory's focused integration
exercises the actual two-workspace cargo-sort/rustfmt commands in such a checkout.
Pins, dependencies, the snapshot roster and actual clone activation stay unchanged.
[Shared #89](https://github.com/dragginzgame/shared-tooling/issues/89).

shared hook correction. Memory's focused adapter checks pass against the selected

## [0.33.1] - 2026-10-09

Failed release preparation leaves a metadata file in place when its bytes
already match the saved backup. This avoids replacing untouched files,
broadening private permissions and introducing unnecessary restoration errors.
Changed, owned replacements still roll back; concurrent edits, original errors,
actual restoration failures and qualification evidence remain preserved.
[#39](https://github.com/dragginzgame/ic-memory/issues/39).
