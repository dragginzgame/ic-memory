# Detailed notes for 0.33

## [0.33.1] - 2026-10-09

Failed release preparation leaves a metadata file in place when its bytes
already match the saved backup. This avoids replacing untouched files,
broadening private permissions and introducing unnecessary restoration errors.
Changed, owned replacements still roll back; concurrent edits, original errors,
actual restoration failures and qualification evidence remain preserved.
[#39](https://github.com/dragginzgame/ic-memory/issues/39).

[Qualification](../release-workflow-qualification.md#0331-untouched-metadata-rollback)

[Current package review](../release-workflow-qualification.md#0331-shared-023-and-host-092)

Correctly numbered pending root and detail entries can be finalized even when
their bodies contain no prose. Notes remain a maintenance obligation; their
content is no longer an executable release gate. Version/date agreement,
duplicate-entry refusal, source/index/payload admission and package receipts
remain enforced. Historical content keeps its original bytes, including a
missing terminal newline. [#40](https://github.com/dragginzgame/ic-memory/issues/40).

## [0.33.0] - 2026-10-09

- **Breaking:** retire both copied fleet reporters and their snapshot records.
  Run fleet Rust reports with `make cloc` in Shared Tooling and CI/tooling reports
  with `make cloc-tooling` there. Memory retains its own workspace report and
  independent-manifest selection. An omitted optional fleet target reports its
  owner without invoking a sibling. The source owner keeps the implementations
  and their regression coverage. [#34](https://github.com/dragginzgame/ic-memory/issues/34).
- Adopt the 86-file Shared Tooling 0.2.2 snapshot at
  `ee48bb37c98c771e77b92fd891f0757d8c1c8b99`. CI installers use exact-path atomic
  publication: late directories refuse without touching their contents, failed
  candidates remain retained, and late symlink targets remain untouched. Perl is
  admitted before setup. Tool pins, both dependency graphs and library/runtime
  contracts stay unchanged. [Shared #88](https://github.com/dragginzgame/shared-tooling/issues/88).
